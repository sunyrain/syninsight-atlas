# Reaction pathway figures

Click a product/path name in the main dataset table to open a connected overview of every recorded operation in that path. All 635 paths are covered. Shared intermediates connect successive operations; convergent branches merge at their recorded reaction. The selected target is highlighted. Long routes continue across rows, with arrows connecting the rows. Each row reads left to right. Reaction conditions sit above the arrow; yield and operation number sit below.

The viewer opens in Whole route mode. Fit width and percentage zoom support closer inspection, and Download SVG provides a vector figure. The separate Filter this path button narrows the table without opening the viewer.

Connectivity comes from the source dataset compound IDs and ordered steps. A regenerated compound receives a new occurrence, preserving reaction cycles without introducing speculative connections. Structures use existing canonical SMILES and RDKit monochrome vector depictions with stereobonds. Existing conditions and yields accompany operation nodes. Missing structures and conditions are explicitly identified. Missing upstream steps are not invented; the case report defines the recorded scope and remains authoritative for mixture yields and unresolved source issues.

The primary figures are generated by `scripts/build_route_overviews.py` in `assets/route-overviews/`, indexed by `assets/route-overviews.json`. Previously generated individual-step schemes in `assets/route-figures/` remain supplementary assets. Rebuild the complete website with `scripts/build_web.py`; validate static links and route coverage with `scripts/validate_web.py`. RDKit is required in the project environment.

These are source-grounded candidate figures. Independent chemical review and journal-specific final dimensions remain separate from automatic rendering.

## Journal-style rendering (September 2026)

The primary renderer uses monochrome structures, open reaction arrowheads, bold source compound labels and a white background. RDKit flexible canvases preserve large structures instead of shrinking them into fixed boxes. A normalization pass gives every depicted molecule the same median bond length. No stereocentres, atom mappings or abbreviations of molecular structure are inferred.

The SVG has explicit physical dimensions: one viewBox unit represents 0.5 pt. Nominal bonds are 14.4 pt, bond strokes approximately 0.6 pt, and conditions and atom labels approximately 8 pt. These proportions reference [ACS chemical structure guidance](https://researcher-resources.acs.org/publish/author_guidelines?coden=aastgj). This is not a claim of conformance to every ACS stylesheet parameter. Atom glyphs are vector paths; condition text remains editable Arial/Helvetica text. Source labels, existing yields and full conditions are preserved (full conditions also appear in SVG title metadata).

The complete pathway is a vector master, not a universally sized journal plate. Complex pathways can exceed a journal column or page width at the native chemical scale; split or reflow them to the target journal's dimensions instead of reducing lettering below its minimum. Dataset quality status remains visible on the website and in the figure caption. Styling does not replace chemical review.
