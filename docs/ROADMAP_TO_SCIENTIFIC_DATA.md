# Roadmap to a formal data publication

The online candidate release establishes the schema, provenance boundary, and public
inspection surface. It is not yet sufficient for a Scientific Data submission.

The first formal release requires:

1. two-reviewer paper admission for the frozen candidate universe;
2. source-concordant structures and explicit stereochemistry for the released target
   denominator;
3. ordered literature routes or source-bound strategic key steps with independent
   review;
4. article-family and scaffold-grouped train/evaluation splits;
5. blinded expert route-value annotations and inter-rater statistics;
6. benchmark loaders, baseline outputs, and complete failure denominators;
7. archival deposition with a DOI and a frozen checksum manifest;
8. a datasheet covering licensing, known biases, missing sources, and update policy.

Candidate and admitted releases must remain distinguishable in filenames, metadata,
the website, and citations.
